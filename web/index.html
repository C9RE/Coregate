This page

This is your Dimraeth server's own page, served by the COREGATE dedicated host itself. Share the address with your players: anyone who opens it sees the map and who is on. The console, the block list and the alerts need the admin password from the server's config file, and the password stays in the browser it was typed in.

Map

The world as the game draws it, one tab per area, with every adventurer's live position, the Gates and crystals they have found, and the Sanctum's buildings. Scroll to zoom, drag to pan. The layers button hides and shows each kind of marker and the veil over unexplored ground.

Console

The server's live log and a command line. The quick actions on the right run the common ones; help lists everything.

Players

Everyone connected, and the block list.

Alerts

Discord messages the server posts itself: joins, leaves, deaths, a full server, start and stop. It cannot tell you the server is down; only something outside the server can.

Unlock owner controls

The admin password is Password under [Admin] in BepInEx/config/com.coregate.admin.cfg. It unlocks the console, player controls and alerts on this page.
